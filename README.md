This repo hands in one X quote post of make.fun's make-your-own-bounty announcement. POST.json names that post and main.ts validates its status URL before copying it to the output the gate reads. The post itself is the entry, ranked by its replies plus reposts plus quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
